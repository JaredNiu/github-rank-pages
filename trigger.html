触发 update-rank

需要一枚能触发工作流的令牌。推荐用 fine-grained token：Settings → Developer settings → Personal access tokens → Fine-grained tokens，只选 github-rank-pages 这一个仓库， 权限给 Actions: Read and write 即可（Metadata 只读会自动带上）。 令牌只存在你自己浏览器的 localStorage，不会发给除 GitHub 以外的任何地方。
